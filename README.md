# OpsDesk

OpsDesk is a modern Single Page Application (SPA) for managing IT support operations. It provides ticket management, customer management, job tracking, audit logs, user authentication, and role-based access control using JavaScript, HTML, and CSS.

## Features

- Dashboard Overview
- Ticket Management
- Customer Management
- Job Management
- Audit Logs
- User Management
- Login Authentication
- Role-Based Access Control (RBAC)
- Offline Queue Support
- Request Manager
- Dashboard Polling
- Local Storage Persistence
- Form Validation
- Error Handling
- SweetAlert2 Notifications

## User Roles

- Administrator
- Operations Lead
- Engineer
- Support Agent

Each role has different permissions for accessing application modules.

## Technologies

- JavaScript (ES6 Modules)
- HTML5
- CSS3
- SweetAlert2
- Local Storage API

## Running the Project

1. Clone or download the project.
2. Open it using a local web server (WAMP, XAMPP, or VS Code Live Server).
3. Navigate to the project URL.
4. Login using the default administrator account.
