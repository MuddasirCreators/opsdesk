## Overview

OpsDesk is a modern Single Page Application (SPA) developed as the **JavaScript Hero Intern Capstone Assignment**. It provides an API Operations & Support Console for managing support tickets, customers, background jobs, audit logs, user authentication, and role-based access control using Vanilla JavaScript.

---

## Features

- 📊 Dashboard Overview
- 🎫 Ticket Management
- 👥 Customer Management
- ⚙️ Job Management
- 📝 Audit Logs
- 👤 User Management
- 🔐 Login Authentication
- 🛡️ Role-Based Access Control (RBAC)
- 📦 Offline Queue Support
- 🔄 Request Manager
- 📡 Dashboard Polling
- 💾 Local Storage Persistence
- ✅ Form Validation
- ⚠️ Error Handling
- 🔔 SweetAlert2 Notifications

## Getting Started

1. Clone the repository

```bash
git clone https://github.com/MuddasirCreators/opsdesk.git
```

2. Install dependencies

```bash
npm install
```

3. Start the development server

```bash
npm run dev
```

4. Open the application in your browser and log in using the default administrator account.
