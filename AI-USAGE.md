# AI Usage

This project was developed with the assistance of ChatGPT.

AI assistance was used for:

- Understanding JavaScript concepts.
- Explaining browser APIs.
- Learning ES Modules.
- Understanding project architecture.
- Creating reusable modules.
- Reviewing and improving code.

All code was reviewed, understood, tested, and executed manually before being included in the project.

The project was completed as a learning exercise to understand modern JavaScript development practices.
